# Appendix C — Creative Guardrails

Whenever a design decision is made,

ask these questions.

---

Does this feel unmistakably MindRoute?

If not,

reject it.

---

Could this exist on another startup website?

If yes,

redesign it.

---

Does this strengthen identity?

Or simply add functionality?

Identity wins.

---

Does this interaction communicate meaning?

Or only visual interest?

Meaning wins.

---

Does this animation explain something?

Or simply decorate?

Explanation wins.

---

Does this component deserve to exist?

If not,

remove it.

---

Does this feature reduce cognitive load?

Or increase it?

Reduce.

---

Would Apple remove this?

Would Aesop simplify this?

Would a museum include this?

If the answer is yes,

you're probably close.

---

Can one element be removed without weakening the experience?

If yes,

remove it.

---

Would someone remember this because it is beautiful,

or because it made them feel something?

Always choose emotion.
