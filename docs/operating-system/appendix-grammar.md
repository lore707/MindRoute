# Appendix B — MindRoute Grammar

## DO

✓ Build scenes, not sections.

✓ Reveal, never explain.

✓ Let photography define space.

✓ Let typography create emotion.

✓ Keep the interface secondary.

✓ Use darkness intentionally.

✓ Allow silence.

✓ Preserve continuity.

✓ Design transitions before components.

✓ Think architecturally.

✓ Prefer atmosphere over decoration.

✓ Reduce before adding.

✓ Ask what the visitor should feel before deciding what they should see.

✓ One emotional idea per viewport.

✓ Every movement has purpose.

✓ Every color has meaning.

✓ Every interaction acknowledges the visitor.

✓ Every feature reinforces identity.

✓ Every decision should feel inevitable.

---

## DON'T

✗ Don't build SaaS pages.

✗ Don't stack feature cards.

✗ Don't explain everything immediately.

✗ Don't overload a screen.

✗ Don't animate for spectacle.

✗ Don't use color to attract attention.

✗ Don't fill empty space.

✗ Don't reveal entire sections simultaneously.

✗ Don't use trendy UI patterns because they are fashionable.

✗ Don't introduce unnecessary interactions.

✗ Don't create components before defining the narrative.

✗ Don't separate design from engineering.

✗ Don't optimize away emotion.

✗ Don't copy existing travel websites.

✗ Don't make AI the protagonist.

✗ Don't let technology become visible.

✗ Don't break continuity between scenes.

✗ Don't let implementation override philosophy.
