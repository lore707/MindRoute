# 04 — Layout Principles

## Core Philosophy

The layout is not a sequence of sections.

It is one uninterrupted journey.

Users should never perceive where one section starts or ends.

Every scene should naturally evolve into the next.

The landing behaves like one long cinematic shot.

Never like stacked website blocks.

---

# Layout Before Components

Never start by thinking about components.

Never think:

Hero

Cards

Features

Testimonials

CTA

Instead think:

Scene

Emotion

Composition

Depth

Transition

Only after those are defined should interface elements appear.

---

# One Dominant Idea Per Screen

Every viewport communicates exactly one idea.

Never two.

Never three.

Never overload.

Examples:

One image.

One sentence.

One emotion.

One interaction.

If a screen contains too many competing elements,
remove something.

Clarity creates luxury.

---

# Editorial Composition

Think like an editorial magazine.

Not like SaaS.

Use asymmetry.

Large empty spaces.

Unexpected alignments.

Oversized photography.

Tiny labels.

Generous breathing room.

Never perfectly centered everything.

Avoid repetitive layouts.

---

# Visual Rhythm

Alternate visual density.

Example:

Huge landscape.

↓

Minimal typography.

↓

Complex animated network.

↓

Almost empty space.

↓

Immersive photography.

↓

Product interface.

↓

Dark silence.

The experience should breathe.

---

# Negative Space

Darkness is part of the composition.

Do not try to fill empty areas.

Large empty regions increase focus.

Luxury products are comfortable with silence.

The absence of elements is intentional.

---

# Screen Hierarchy

Every viewport contains:

Primary focus

Secondary support

Atmosphere

Nothing else.

The eye should immediately understand where to look.

Never create visual competition.

---

# Photography Integration

Images should not sit inside cards.

Images define space.

Typography lives inside photography.

The interface emerges from photography.

Photography continues beyond its own section.

Images should bleed into the following scene.

---

# Typography Placement

Typography is part of the landscape.

Never place text inside obvious content boxes.

Let words breathe.

Allow dramatic margins.

Create tension through positioning.

Sometimes left.

Sometimes right.

Sometimes floating.

Never mechanically centered throughout the experience.

---

# Product Placement

The product is revealed gradually.

Do not expose the interface immediately.

For the first half of the landing,
sell the philosophy.

Only afterwards reveal the product.

The interface should feel like the natural consequence of everything the visitor has just understood.

---

# Interface Density

The amount of UI should increase progressively.

Beginning:

Almost no interface.

Middle:

Hints.

Fragments.

Small previews.

End:

Complete product.

The visitor earns the interface.

---

# Layer System

Every scene consists of multiple independent layers.

Layer 01

Background atmosphere.

Layer 02

Photography.

Layer 03

Animated network.

Layer 04

Particles.

Layer 05

Typography.

Layer 06

Interactive elements.

Layer 07

Product UI.

Each layer has its own movement.

Each layer has its own depth.

---

# Visual Anchors

Every section must contain one memorable visual anchor.

Examples:

A huge landscape.

A network expanding.

Two itineraries diverging.

A glowing travel graph.

A memory timeline.

A floating destination.

Never rely only on text.

People remember images.

Not paragraphs.

---

# Progressive Complexity

The experience starts simple.

Then grows richer.

Then becomes minimal again.

The visual complexity follows the emotional narrative.

Not the information architecture.

---

# Scroll Continuity

Background elements continue between sections.

The network never disappears completely.

Particles survive transitions.

Light continues travelling.

Photography overlaps scenes.

Nothing resets.

Every transition feels physically connected.

---

# Avoid Website Patterns

Avoid:

Three-column features.

Icon grids.

Alternating image/text blocks.

Pricing-table composition.

Centered testimonials.

SaaS feature sections.

Repetitive cards.

Generic dashboard layouts.

If it looks like a startup template,
it is wrong.

---

# Build Scenes

Each section should first answer:

What does the visitor feel?

Then:

What do they see?

Then:

How does the world move?

Only then:

Where do buttons go?

---

# Responsive Philosophy

Responsiveness is not scaling.

It is recomposing.

Desktop and mobile should feel equally cinematic.

Layouts may completely change.

The emotion must remain identical.

Never simply stack desktop elements vertically.

---

# Final Principle

If all interface elements disappeared,
the visitor should still understand the story.

The layout itself should tell the narrative.

The UI is only the final layer.

Never the foundation.
