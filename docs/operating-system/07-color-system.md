# 07 — Color System

## Color Philosophy

Color is not decoration.

Color is attention.

If everything is colorful,
nothing is important.

MindRoute uses color with extreme restraint.

Darkness is the default.

Light is the exception.

Accent color is a signal.

Every color choice must communicate intention.

Never aesthetics alone.

---

# Emotional Palette

The emotional palette of MindRoute is built around contrast.

Darkness.

↓

Warm light.

↓

Small coral accents.

↓

Silence.

The experience should feel contemplative.

Not energetic.

The visitor should feel calm.

Not excited.

---

# The World Lives In Darkness

Darkness is not empty.

Darkness is space.

Darkness allows imagination.

Darkness creates focus.

Darkness lets photography breathe.

Darkness lets motion become visible.

The interface should always emerge from darkness.

Never sit on top of it.

---

# Background System

Avoid pure black (#000000).

Pure black feels digital.

Instead use layered dark tones.

Very dark charcoal.

Graphite.

Deep blue-black.

Warm black.

Multiple shades should blend together almost invisibly.

Backgrounds should feel atmospheric.

Not flat.

---

# The Coral

Coral is not branding.

Coral is intention.

It exists only to communicate meaning.

Examples:

Current focus.

Identity.

Connections.

Discovery.

Progress.

Memory.

Never use coral to decorate.

Never large coral surfaces.

Never coral gradients.

Never coral backgrounds.

Coral should always feel precious.

Almost rare.

---

# White

White should never be perfectly white.

Use warm whites.

Soft ivory.

Very light gray.

Slightly reduced brightness.

Typography should feel printed.

Not illuminated.

---

# Gray System

Grays are structural.

Not emotional.

Used for:

Metadata.

Secondary interface.

Navigation.

Supporting information.

Never use gray to reduce importance.

Use opacity instead.

---

# Color Hierarchy

Emotion

↓

Photography

↓

Typography

↓

Coral accents

↓

UI

The interface should never become the most colorful element.

---

# Light

Light is a design material.

Not an effect.

Use soft volumetric lighting.

Ambient glow.

Subtle reflections.

Gentle gradients.

Light should reveal objects.

Never decorate them.

---

# Glow

Glow should be almost invisible.

Very low intensity.

Large radius.

Warm.

Soft.

Never neon.

Never cyberpunk.

Never gaming.

Glow should feel like morning light.

Not LEDs.

---

# Gradients

Gradients should imitate nature.

Fog.

Sunrise.

Clouds.

Mist.

Atmosphere.

Never rainbow gradients.

Never saturated transitions.

Never obvious digital effects.

---

# Transparency

Transparency creates depth.

Glass creates elegance.

Use transparency sparingly.

Only when it helps separate layers.

Glass should never become the visual identity.

It is a supporting material.

Not the protagonist.

---

# Contrast

Contrast should emerge through:

Scale.

Light.

Motion.

Depth.

Only secondarily through color.

Avoid aggressive contrast.

Luxury products whisper.

They never shout.

---

# Photography Color Treatment

Photography should feel coherent.

Muted saturation.

Warm highlights.

Soft shadows.

Natural skin tones.

Deep blacks.

Low contrast skies.

No oversaturated landscapes.

No Instagram travel look.

Images should feel timeless.

---

# The Network

The network is primarily light.

Not color.

Connections appear through subtle luminosity.

Nodes breathe softly.

Signals glow briefly.

The network should feel like starlight.

Not interface graphics.

---

# Interactive States

Hover:

Slight increase in brightness.

Small coral hint.

Tiny glow.

Focus:

Calm.

Precise.

Elegant.

Click:

Soft compression.

Never bright flashes.

Never colorful animations.

---

# Forbidden

Never use:

Pure black.

Pure white.

Neon.

Blue glows.

Purple gradients.

Rainbow colors.

Heavy shadows.

Bright borders.

Marketing colors.

Startup blues.

Crypto aesthetics.

Cyberpunk palettes.

Gaming aesthetics.

Glassmorphism overload.

---

# Emotional References

The palette should feel closer to:

Aesop stores.

Apple keynote stages.

Luxury hotels at night.

Japanese architecture.

Museum lighting.

Editorial photography.

High-end watch boutiques.

Architectural visualization.

The visitor should feel surrounded by atmosphere.

Not interface.

---

# Final Principle

If every accent color disappeared,

the landing should still feel premium.

If every photograph disappeared,

the atmosphere should still exist.

Color should never carry the experience.

It should quietly reinforce it.

The visitor should never think:

"This is a beautiful color palette."

They should think:

"This place feels different."

That feeling is the true color system.
